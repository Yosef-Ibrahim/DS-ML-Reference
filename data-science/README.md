This track contains the mathematical and statistical foundation required to
understand data analysis and machine learning. It is intentionally separate
from the `machine-learning/` track: these folders explain *why* algorithms
work, while the modeling track explains how to train and evaluate them.

## Learning order

```text
Linear equations → vectors → matrices → linear systems → eigenvectors
                 → descriptive statistics → variation → z-scores
                 → correlation → regression
```

| Folder | Contents | Why it matters later |
|---|---|---|
| [`linear-algebra/`](./linear-algebra/) | Seven ITI lessons on equations, vectors, matrices, systems, and eigenvectors | Features are vectors, model parameters are vectors, and transformations are matrices |
| [`statistics/`](./statistics/) | Eleven ITI lessons on graphs, spread, z-scores, correlation, and regression | Evaluation, uncertainty, outliers, and model assumptions depend on statistical reasoning |

## How the source conversion works

The original ITI PDFs are preserved in each `pdfs/` folder. The Markdown
references reorganize their content into numbered sections, add missing context,
connect each lesson to machine learning, and record explicit `⚠️ Correction`
notes when the source contains an ambiguity or an unsafe shortcut. Computational
examples are kept small and reproducible so they can be tested locally.
