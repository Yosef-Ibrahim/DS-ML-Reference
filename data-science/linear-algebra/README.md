This folder reorganizes the seven ITI Linear Algebra lessons into a progression
from equations to eigenvectors. The original PDFs are preserved under `pdfs/`;
the reference guide explains the mathematics and its connection to machine
learning.

## Files and learning order

| Order | Source | Main idea |
|---:|---|---|
| 01 | `01-linear-equations.pdf` | One-variable and simultaneous linear equations |
| 02–03 | `02-vectors-part-1.pdf`, `03-vectors-part-2.pdf` | Vector representation, operations, length, and geometric meaning |
| 04 | `04-matrices.pdf` | Matrix structure, operations, transpose, and transformations |
| 05 | `05-solving-linear-equations-matrix-inverse.pdf` | Matrix form `Ax=b`, inverse matrices, and elimination |
| 06 | `06-special-cases-linear-systems.pdf` | Unique, inconsistent, and underdetermined systems |
| 07 | `07-eigenvectors.pdf` | Eigenvalues, eigenvectors, and invariant directions |

Read [`Linear_Algebra_Reference.md`](./Linear_Algebra_Reference.md) before
opening the exercises. It explicitly distinguishes exact hand calculation from
numerical computation, because floating-point arithmetic can make a theoretically
zero determinant appear as a very small non-zero number.
