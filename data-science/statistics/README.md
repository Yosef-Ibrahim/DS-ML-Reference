This folder reorganizes the eleven ITI Statistics lessons into a practical
sequence. The original PDFs are in `pdfs/`; the reference guide explains what
each lesson contributes to exploratory analysis and machine learning.

## Files and learning order

1. Introduction and data summaries.
2. Graph selection and visual communication.
3. Quartiles and interquartile range.
4. Variance and standard deviation.
5. Z-scores and standardization.
6. Correlation and Pearson's coefficient.
7. Regression lines, best fit, and regression analysis.
8. A complete regression example.

See [`Statistics_Reference.md`](./Statistics_Reference.md) for the source-file
mapping, formulas, assumptions, and correction notes.
