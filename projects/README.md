## Recommended project workflow

1. Read the project README and identify the business question.
2. Check prerequisites and inspect the input schema before running code.
3. Run the smallest reproducible example first.
4. Read the SQL, Python, or notebook implementation in execution order.
5. Validate outputs, document assumptions, and record limitations.
6. Extend the project only after the baseline is reproducible.

Every project directory contains its own detailed steps, requirements, source
files, and validation notes. Track-specific guidance remains in the corresponding
curriculum README.
